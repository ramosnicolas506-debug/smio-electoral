Conectar Firebase

Este sistema necesita Firebase Realtime Database para guardar candidatos y votos en la nube. Es gratis. Sigue estos pasos una sola vez:

1Ve a console.firebase.google.com → crear proyecto → nombre: smio-electoral
2En el proyecto: Realtime Database → Crear base de datos → Modo prueba (test mode)
3Configuración del proyecto (ícono ⚙️) → Tus apps → </> Web → Registrar app → Copia los valores de firebaseConfig
4Pega los valores aquí:

La configuración se guarda en localStorage de tu navegador.
